# Angular Gridster2 for Explore

Angular Gridster2 library does not support the push pattern (north and south only) that how old Explore was used to work with the old (deprecated) Angular Gridster.
Therefore, we had to clone and modify the library ourselves, to cater the behavior we want to achieve.

The base of this library is angular-gridster2 @ version 8.

This library is local to Explore only.
