Vary:
Economy refers to the economic data points used to calculate factor returns and factor volatility; whereas, Exposures refers to the sensitivities, such as duration, that the securities in a portfolio have on a given date. Thus, varying the Economy will change columns like Factor Level and Factor Vol, while varying the Exposures will change columns like Factor Exposure. Certain columns, being a product of both of these inputs, are impacted by both Economy & Exposures. Columns of this type include Credit Beta, Standalone Risk, Risk Contribution, and Stress PnL
