Use DxS for block
Flexible DxS risk factors are risk factors whose exposure does not employ a relative spread volatility by default, but can be converted into the DxS space. Setting this field to ALL_DXS will force both true and flexible DxS risk factors to use a spread volatility. When the checkbox is unchecked and the value of NONE is used, DxS is turned off entirely.

BFRE covariance matrix controls
Shrinkage is applied to the BFRE matrix which makes the matrix easier to invert and more suitable for optimization. Since the BFRE covariance matrix is computed only for BFRE factors, the correlation between non-BFRE risk factors and BFRE risk factors is imposed to be zero to preserve positive definiteness of the covariance matrix. The BFRE covariance matrix, which corresponds to the first option in this setting, should therefore only be used for portfolios that are close to 100% equity.

Exposure lookback
This controls the date tolerance for exposure lookback. For example, if the date is set to T-1B and the lookback is set to 1, then exposures as of T-1B would be queried for first, followed by T-2B if nothing is found for T-1B.
Adjustment to ensure a positive semi definite risk matrix
This is a number between 1 and 100 that determines how much the risk matrix is modified to ensure that it is positive semi-definite. A higher value means more modification and a lower value means less modification. The adjustment factor is multiplied by 1E-8 (the default value) to scale the values of the matrix. Please reach out to Aladdin help for additional guidance and any changes away from the default. There is more guidance on the impact of this adjustment in the Explore user guide.
