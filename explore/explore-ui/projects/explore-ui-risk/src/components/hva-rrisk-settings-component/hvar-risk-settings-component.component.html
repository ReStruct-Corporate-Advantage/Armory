Return Horizon
The Return Horizon works in conjunction with the Window Length to set the number of return periods used to calculate HVaR.
If a horizon of 10 days is set over a 2,520 day window length, then 252 10-day return observations will be used to calculate the HVaR.
For a return horizon of 1 Rolling Week, the analysis date less one week is used as the first return observation. As the analysis date evolves, so will the return period, and the same holds true for the 1 Rolling Month option.
Risk Horizon
When using longer return horizons such as monthly, it can be difficult to source a significant number of return observations. To overcome this, shorter return horizons can be scaled to longer observations using a square root of time multiplier. For example, to scale weekly returns to monthly returns, a value of 20 can be passed into this setting, thereby scaling the results by the square root of the ratio of 20 (days in a monthly return period) over 5 (days in a weekly return period). Ultimately, the number of days to scale up to would be provided in this box. Similarly, if the return horizon is set to 1 day, then the square root of 20 would be applied to the end result, as determined by taking the square root of the ratio between 20 days in a month and a 1 day return horizon.

Confidence Interval Scaling
Some regulations call for the use of a 99% or similarly high confidence interval HVaR. There may, however, be relatively few incidences of a 99% loss event. To ensure that an appropriate amount of return observations are in scope for calculations, a 95% confidence interval can be used with the end results scaled to a 99% confidence interval.
