Export file name
The following fields can be used as dynamic variable names.
These can be added to the export name (brackets should be included and upper case text is required) :
[PORTFOLIO], [DATE], [REPORT], [BENCH], [CURRENCY]
Export download directory
Specify the download directory to download Excel files.

In order to download the files:
- ensure Genie is started
- configure Batch Row(s)
- click the "Run" button

If the directory is left blank, Excel files will be downloaded into the browser's default directory.
(PDF files will always be downloaded into the browser's default directory)
