To run a time series analysis on correlations and regression betas, the left-hand factor table and right-hand factor table must both be populated to control the factor pairs. If Factor A is entered on the left, with Factor B and Factor C entered on the right, then a time series of factor pairs A:B and A:C will be generated. The risk settings used are dictated by the factors selected on the left.
  • Users can define factors based on linear combinations of other factors surrounded by brackets.
  • The factors must be specified based on their tags and not their names, e.g. [0.5*USD_10yr-0.2*JPY_10yr].
  • Additionally, STORM factors can be defined by using an '@' followed by the CUSIP, e.g. @260557103.
