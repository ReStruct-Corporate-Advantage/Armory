When adding a security to a specific portfolio in a portfolio group, the current value reflects that of the entire portfolio group and the new value reflects the desired final exposure to the selected portfolio.
So, for a portfolio group with 2% exposure to an asset, 1% of which is coming from Portfolio A, specifying a new value of 4% when Portfolio A is selected would yield 5% portfolio group exposure to an asset, 4% of which is coming from Portfolio A.
